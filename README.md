# Receitas Mauro Backend

Backend da aplicação Receitas Mauro.

## Endpoints
- `GET /health`
- `POST /extract/url`
- `POST /extract/text`
- `POST /extract/file`

## Render
Este repositório está preparado para ser publicado no Render através do `render.yaml`.

No Render é necessário definir:
- `GEMINI_API_KEY`
- `GEMINI_MODEL` (por defeito: `gemini-2.5-flash`)

A chave nunca deve ser colocada diretamente no GitHub.
